Check that it is up:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "discourse.fullname" . }} 3000:{{ .Values.service.port }}
  curl http://localhost:3000/srv/status

Create the first admin account (asks for email and password):

  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "discourse.fullname" . }} -- rake admin:create

Then open https://{{ .Values.discourse.hostname }}{{ if not .Values.ingress.enabled }} (no Ingress is created by this release; route that hostname to the Service){{ end }}.
When the forum is served over HTTPS, turn on Admin > Settings > Security > "force https",
or run:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "discourse.fullname" . }} -- rails runner 'SiteSetting.force_https = true'

Without it Discourse generates http:// links.

NOTE: smtp.address is not set, so Discourse can't send sign-up, password reset
or notification emails. Set the smtp.* values before you invite users.
{{- end }}
